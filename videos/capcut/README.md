# CapCut VFX library videos

Place the short square CapCut VFX loops referenced by `capcutVfxItems` in this folder.

Recommended exports:

- 1:1 square H.264 MP4
- 540x540 or 720x720
- Muted, seamless 2-6 second loop
- Approximately 1-3 MB per clip
- Use the existing filenames or update `src/data/effects.js`
